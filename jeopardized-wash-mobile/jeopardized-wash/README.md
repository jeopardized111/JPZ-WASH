# Jeopardized Wash

Сайт-прототип сервиса прогноза для мойки автомобиля.

## Что исправлено
- Регистрация больше не показывает `Failed to fetch`, если `index.html` открыт двойным кликом или сервер временно недоступен.
- В регистрации можно выбрать способ связи: почта или телефон.
- Для телефона добавлен выбор страны с кодом: Россия +7, Казахстан +7, Беларусь +375, Армения +374, Грузия +995, Узбекистан +998, Украина +380, Германия +49, Великобритания +44, США +1.
- Номер форматируется автоматически.
- В режиме без сервера профиль и опрос сохраняются локально в браузере.
- При запуске через Node.js используются серверные API и общий файл `data.json`.
- Давление переведено из hPa в мм рт. ст.

## Запуск полноценной версии

1. Установить Node.js 18+.
2. Открыть терминал в папке проекта.
3. Выполнить:

```bash
npm install
npm start
```

4. Открыть `http://localhost:3000`.

## Быстрый запуск без сервера

Можно открыть `public/index.html` двойным кликом. Основной прогноз и выбор города работают через публичный Open-Meteo API. Регистрация, профиль и опрос в этом режиме сохраняются только в текущем браузере.

Для общей таблицы лидеров между разными пользователями нужен запуск через Node.js.

## Погода

Используется Open-Meteo. Текущие условия и прогноз запрашиваются по координатам выбранного города. Фон переключается между изображением ясной погоды и изображением дождя/плохой погоды по коду текущей погоды.

## Важно для реального запуска

Для настоящих SMS/e-mail уведомлений понадобится подключить отдельный сервис отправки сообщений и хранить его ключи только на сервере. В текущем проекте контакт сохраняется, но сообщения автоматически не отправляются.

### Что обновлено в этой версии
- Погодный запрос использует явные единицы: °C, м/с и мм, а часовой пояс берётся автоматически для выбранного города.
- Добавлены почасовые погодные данные для дальнейшего более точного расчёта рекомендаций.
- Давление переводится из hPa в мм рт. ст. корректно.
- Переключатель темы меняет значок: ☀ в светлой теме и ☾ в тёмной.
- В профиле можно загрузить собственное JPG/PNG/WebP-фото; изображение автоматически уменьшается до 256×256 и сохраняется как аватар.
- Сервер принимает сжатые аватары через JSON-запросы до 2 МБ.
- Текст и контраст бокового меню улучшены для светлой и тёмной темы.
